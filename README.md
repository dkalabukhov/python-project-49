# Brain Games (Python)

The game consists of four console mini-games:

# Installation
Run following commands in a given order:
```
make install

make build

make package-install
```

## Brain Even
Type brain-even in console to start the game.
The game shows random number and you need to answer 'yes' if the number is even or
'no' if the number is odd:
[![asciicast](https://asciinema.org/a/1270824.svg)](https://asciinema.org/a/1270824)

## Brain Calc
Type brain-calc in console to start the game.
The game shows a simple mathematic expression and you need to type the correct number
as the result of the expression:
[![asciicast](https://asciinema.org/a/1270912.svg)](https://asciinema.org/a/1270912)

## Brain GCD
Type brain-gcd in console to start the game.
You get two random numbers and need to figure out their greatest common divisor
[![asciicast](https://asciinema.org/a/1270915.svg)](https://asciinema.org/a/1270915)

## Brain Progression
Type brain-progression in console to start the game.
You get progression with a hidden number (..) and you need to figure out the hidden number
[![asciicast](https://asciinema.org/a/1271557.svg)](https://asciinema.org/a/1271557)
