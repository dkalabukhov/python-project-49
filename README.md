# Brain Games (Python)

The game consists of five console mini-games:

# Installation
Run the following commands in the given order:

```
make install

make build

make package-install
```

## Brain Even
Type brain-even in the console to start the game.
The game shows a random number, and you need to answer 'yes' if the number is even or
'no' if the number is odd:
[![asciicast](https://asciinema.org/a/1270824.svg)](https://asciinema.org/a/1270824)

## Brain Calc
Type brain-calc in the console to start the game.
The game shows a simple mathematical expression, and you need to type the correct number
as the result of the expression:
[![asciicast](https://asciinema.org/a/1270912.svg)](https://asciinema.org/a/1270912)

## Brain GCD
Type brain-gcd in the console to start the game.
You get two random numbers and need to figure out their greatest common divisor:
[![asciicast](https://asciinema.org/a/1270915.svg)](https://asciinema.org/a/1270915)

## Brain Progression
Type brain-progression in the console to start the game.
You get a progression with a hidden number (..), and you need to figure out the hidden number:
[![asciicast](https://asciinema.org/a/1271557.svg)](https://asciinema.org/a/1271557)

## Brain Prime
Type brain-prime in the console to start the game.
You get a random number and need to decide if it's prime or not:
[![asciicast](https://asciinema.org/a/1271559.svg)](https://asciinema.org/a/1271559)
